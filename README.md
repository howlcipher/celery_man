# Celery Man - Cinco OS

Welcome to the Cinco OS Identity Generator 2.5! This repository is purely a gag aimed at the concept of prompt engineering, inspired directly by the legendary [Tim and Eric sketch](https://youtu.be/maAFcEU6atk). This is a fun, interactive web recreation of that classic "Celery Man" sequence.

## Features
- **Authentic Cinco OS UI**: A draggable, retro 90s-style window straight out of "Paul's Computer".
- **Sequence Generator**: Load up Celery Man, Oyster Smiling, and Tayne.
- **Modifiers**: Kick up the 4d3d3d3, generate a Hat Wobble, or trigger a Flarhgunnstow.
- **Physical Printouts**: Get a real-time (virtual) printout of Oyster Smiling.
- **Security**: Nude Tayne is strictly prohibited by Cinco Corporation and will trigger a system warning.

## How to use
Visit the [GitHub Pages link](https://howlcipher.github.io/celery_man/) and use the on-screen buttons or the terminal input to execute commands.
